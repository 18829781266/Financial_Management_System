# 异常缺失标记保留与复核入口

2026-11-16，本地版本。

## 问题与处理

已通过真实页面操作复现：先将两张凭证分别标记附件缺失，再保存复核同期间第三张凭证，前两张的缺失状态被匹配重算覆盖。缺失标记是人工业务决定，其他凭证的字段保存和自动匹配不能隐式解除它。

缺失凭证应保留缺失状态、原因与已承诺的分摊占用，不再参与自动匹配候选竞争。普通字段编辑也不表示补齐附件；明确恢复待匹配或人工补齐原件并确认关联，继续使用原有流程。

## 界面

- 匹配状态为“待人工复核”的凭证，将原“编辑”按钮改为“人工复核”，沿用原编辑与复核事件；附件缺失及待匹配行仍显示“编辑”。
- 异常凭证页筛选提供“附件缺失”和“待人工审核”，保留“全部状态”作为重置。“待人工审核”排除已标记缺失的记录；异常单据页仅提供其实际适用的待审核选项。其他页面的状态选项保持原样。
- 异常处理顶部四张统计卡复用工作台和电子档案的悬停反馈：上移 3px、轻阴影、图标上移 2px 并放大至 1.05 倍，移出恢复，兼容键盘及减少动态效果设置。
