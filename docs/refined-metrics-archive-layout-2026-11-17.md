# 统计卡新方向与档案全宽证据区

2026-11-17，本地修改与验收。

> 历史阶段记录：本文的全宽单据与预览布局已在后续按用户要求调整为“左侧归档目录独占一列，单据和预览位于右侧”。当前界面以 DESIGN.md 的 Archive Directory 为准；工作台浅色居中统计卡继续保留。

## 界面修改

- 工作台四项统计采用“图标、居中数字、标题”的竖向顺序；使用现有图标配色中的蓝、青绿、淡紫、米杏极浅纸面，数值仍为深蓝。不增加说明小字、进度条或额外装饰。三张可操作卡保留原列表入口，覆盖率保持静态指标；继续支持悬停、键盘、触屏和减少动态效果。
- 已关联资料的两列布局仅用于上方公司目录与公司概览、关联凭证。单据表、分页和原件预览移入独立 archive-evidence，跨整个内容栅格宽度，避免长 PDF 旁一直预留公司目录的空列。目录高度随内容收紧；每页六条单据完整显示。
- 公司与期间分组、搜索、凭证与单据分页、预览范围、复核入口、正式生成和已有档案跳转沿用原数据计算与事件。
