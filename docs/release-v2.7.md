# 汇通云 V2.7：逐行核对凭证附件

## 本次变更

- “核对凭证附件”独立弹窗仅展示摘要、科目、借方、贷方、附件单据。每行只显示真正绑定到该分录的原始单据，可直接打开原件。
- 自动匹配按回单逐一查找凭证分录：金额精确到分且完全一致，收款账号或至少4位尾号在科目中，业务日期差严格小于30天。正好30天不自动关联。
- 收款账号与付款账号分别提取并以文本保存，保留前导零；不使用流水号或付款账号冒充收款账号。双方均有完整账号时，账号不同不能仅因尾号相同而关联。
- 同一回单命中多个分录，或多份等价回单竞争一个分录时，全部交人工复核。按单月执行也检测相邻期间的候选歧义。
- 关联关系保存凭证ID、分录下标和单据ID；成功后在本系统回单记录的备注中追加凭证号、会计期间及分录行号，保留用户原备注，重复运行不重复追加。此操作不修改原始PDF，也未接入外部银行系统。
- 已匹配分录可先保留；存在未完成的银行分录时，整张凭证仍显示“请复核”。人工复核按具体行选择附件，金额合计须等于该行金额，账号或日期例外须填写依据。
- 解除关系及删除相关数据时同步移除分录关系和系统生成的备注行。已锁定档案的关系和数据保持只读。
- 从已保存的文字型PDF中补读旧回单账号。旧版单纯名称归集在用户下次点击自动匹配时按新条件重算，不要求清空或重新上传原件。
- 工作空间升级加入R09，自动匹配不再回退到企业名称归集。停用R09暂停新匹配并保留已有关联。历史R01—R08配置留存，当前规则页展示R09及固定条件。
- 支持JSON的`entries`/`Entries`/`分录`数组与CSV中JSON编码的分录字段。没有逐行数据、没有可用账号或没有可用文字层的文件进入人工复核，不伪造提取值。
- 页面版本更新为V2.7，构建产生`/version.json`供发布后核对实际源码版本。

## 验证

- 前端自动化测试：382项，覆盖金额、账号提取及保真、日期边界、逐行关系、人工复核、状态同步、旧数据升级、锁定边界、幂等备注、跨期冲突及弹窗五列内容。
- Vue/TypeScript检查与生产构建通过。
- 独立服务器适配测试：5项，包含真实HTTP与SQLite登录权限、静态文件、持久化及迁移。
- 本次未能连接用户的浏览器，尚未完成公网浏览器验收，也未在腾讯云执行本次升级。以服务器安装日志、`/version.json`和实际公网页面为上线依据。

## 升级后操作

1. 保持原访问地址，在原浏览器刷新页面，等待历史文字型回单的账号补读完成。
2. 在“智能匹配”点击“开始自动匹配”。原有未锁定自动关系按本次联合条件重算；已锁定档案及人工关系保留。
3. 在“电子档案”打开“核对凭证附件”，逐行查看实际附件；其余进入“异常处理”或使用每行“人工复核”。
4. 数据采集和电子档案单据表均可查看收款账号与回写备注。复核后再生成正式档案册。

服务器继续持久化账号和会话；业务记录与原件仍保存在当前浏览器的localStorage/IndexedDB。本版本没有改变既有数据存储边界。
