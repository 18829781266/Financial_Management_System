# 汇通云 · 电子凭证自动匹配与归档系统

[在线站点](https://119.45.210.141/)

汇通云提供凭证与原始单据批量采集、规则匹配、人工复核、原件翻页及放大、PDF档案册生成与检索。采用 Vue 3、TypeScript、Element Plus；账号与权限由 Cloudflare Worker + D1 提供。仓库同时包含 Java 17 + Spring Boot 3、MyBatis-Plus、MySQL 8、Redis、PDFBox 配套财务业务后端。

## 项目结构

| 目录 | 内容 |
|---|---|
| `frontend/src` | 登录页、用户管理及全部财务工作区源码 |
| `frontend/worker` | 登录、会话、超级管理员创建与删除用户的服务端接口 |
| `frontend/db`、`frontend/drizzle` | 账号表结构、SQL迁移及Drizzle元数据 |
| `frontend/scripts` | 构建、本地管理员配置、D1预览及打包工具 |
| `frontend/tests` | 业务、认证和浏览器测试；仅包含合成夹具 |
| `backend` | Java财务业务API、SQL、OCR适配、匹配引擎、PDF归档及JUnit测试 |

## 本地运行完整站点

需要 Node.js 22.13+（建议24 LTS）。首次克隆后在项目根目录执行：

```sh
npm run setup
npm run auth:configure
npm run build
npm run db:local
npm run dev
```

管理员配置脚本在终端隐藏输入本地初始密码，仅将加盐摘要写入忽略的 `frontend/.sites-runtime/.dev.vars`。首次登录账号为 `admin`、姓名赵会计；密码由本地初始化时自行设置。已有数据库中的账号不会被配置脚本重置。

打开终端显示的 `http://127.0.0.1:5175`。`npm run dev` 运行实际Worker、D1和构建后的Vue页面；修改前端后重新 `npm run build`。`npm run db:local` 只操作本地D1，不连接线上数据库。

## 账号和权限

- 超级管理员可以创建及删除普通用户；普通用户没有用户管理权限。
- 删除前显示目标姓名和账号的确认框；服务端禁止删除超级管理员，并在事务中撤销被删除账号的全部会话。
- 退出登录需二次确认；取消或Escape不会注销。
- 密码使用独立随机盐的PBKDF2-SHA256摘要；登录令牌采用Secure、HttpOnly、SameSite Cookie，数据库只保存令牌摘要。
- 权限逐次由服务端验证，不能通过更改浏览器角色或直接调用接口提升权限。

仓库不包含任何线上密码、密钥、账号数据库或用户上传原件。测试账号仅用于本地隔离测试。

## 数据和业务模块

账号存储在D1，支持在不同浏览器登录。凭证、单据、规则和匹配关系仍保存在当前浏览器的本地存储中，原件及生成的PDF存于IndexedDB；这些财务数据不会因登录而自动跨设备同步。

支持JSON/CSV、PDF、图片及ZIP批量导入，文字型PDF字段提取、凭证续页合并和回单分拆；扫描影像需要补录或接入OCR。规则按配置优先级执行，未关联数据进入“请复核”；只有实际关联的数据展示在电子档案。支持最新导入优先、分页及批量删除、原件按真实版式翻页、单张放大、档案期间和实际凭证范围选择。原件、已有档案哈希及技术存储键在品牌更名时保持兼容。

### V3.2.6 客商归集与金额优先匹配优化

- 异常凭证手工匹配后按已复核的往来客商归入电子档案；往来客商增加填写说明和必填校验，空值保存时显示红色错误。人工确认金额关系后退出旧名称归集组，避免同一凭证重复归集。
- 已匹配但未锁定的凭证允许修改字段并保留原财务关系；正式锁定档案、PDF原始分录金额及归档硬校验继续受保护。
- 合并复核页将“保存并复核字段”放在底部，主操作改为“取消”；唯一金额、账号及日期一致的原始单据直接显示为分录附件候选，但不静默核销，歧义和多解仍转人工。
- 证据链改以凭证摘要、往来客商、匹配方式、金额核对、字段复核、档案状态和关联原件为主，不再以技术节点或置信度作为主体。
- 普通财务规则先收敛金额和日期，再以名称排除同额其他往来对象；汇总规则先找唯一金额组合再核名称。已成立财务关系的凭证和单据不再进入后续名称归集。

### V3.2.5 凭证复核与列表操作优化

- 人工分录复核及附件豁免确认留痕后，关闭主弹窗和子弹窗并直接返回列表；分录复核主弹窗不再显示单独“取消”，右上角关闭和Escape仍可退出，内层复核弹窗保留取消操作。
- 附件缺失凭证在凭证号后显示红色“缺”字，匹配状态显示“附件缺失”及已留痕的具体原因。
- 凭证操作列移除“补录”和“关联穿透”；点击凭证号或双击行仍可查看证据链，已复核凭证保留独立编辑入口。
- 手工匹配将凭证关键字段复核、分录附件复核及候选单据放入同一页面；无分录且待复核的凭证也在通用手工匹配弹窗内完成字段核对。
- 顶栏增加“搜索”按钮，Enter快捷搜索继续有效。
- 工作台移除“本地工作空间”和“前往智能匹配”，收紧标题、指标卡、主视觉及内容区间距，减少无效留白。
- 凭证匹配状态统一为“待匹配／待人工复核／已匹配／附件缺失”，并补充匹配方式、规则号、原件数量或具体复核原因；原始单据状态文案保持不变。
- 320px窄屏修正顶栏面包屑收缩、提示条和弹窗宽度，保留V3.2.4经典滚动条下的布局稳定性。

### V3.2.4 弹窗滚动条布局稳定性修正

- 为根页面预留稳定的滚动条槽，并覆盖 Element Plus 锁屏时临时写入的 body 宽度补偿，消除确认框和普通弹窗打开、取消时列表左右晃动的问题。
- 在具有15px经典滚动条的真实浏览器中连续执行三轮打开与取消，逐帧核对列表、表格和主内容区几何尺寸；取消操作不删除任何凭证，普通弹窗开关也保持布局稳定。

### V3.2.3 全站弹窗视觉与移动端优化

- 统一确认框、输入确认框、表单弹窗、分录复核、批量导入、规则配置、用户管理、附件豁免、档案册范围、原件预览与单页放大的标题层级、正文行距、提示色、固定操作区和按钮状态；危险删除与重置使用独立红色确认操作。
- 保留深蓝品牌、业务文案、按钮行为和全部确定性财务校验；凭证分录复核主弹窗页脚继续使用“确认”和“取消”。
- 手机端扩大主要触控目标并避免按钮换行和横向溢出；补强键盘焦点环、辅助文字对比度及减少动态效果支持。修复原件放大窗口与底层翻页组件的全局指针事件冲突。

### V3.2.2 匹配、复核与日志流程修正

- 每次数据成功导入后立即执行全量自动匹配，智能匹配页不再显示“开始自动匹配”；连续导入会等待当前轮结束后按最新数据再执行，工作台仅保留页面导航。
- 自动匹配成功的凭证不再因“凭证字段尚待复核”被单独拦截，可直接进入正式档案生成；附件字段复核、发票章、金额、附件数量、分录分摊和证据完整性等确定性校验继续执行，人工匹配记录仍须先复核凭证字段。
- 人工复核依据按分录独立保存，清空全部关联后再次进入仍可回显；旧版只存在于人工附件关系中的依据会在恢复时自动迁移。
- 新操作日志记录稳定用户ID和登录账号。普通用户在操作日志页及工作台最近操作中只能看到本人记录，超级管理员可看到全部；无法确认归属的旧日志仅超级管理员可见。
- 凭证分录与原始单据复核主弹窗页脚统一为“确认”和“取消”，原有业务动作保持不变。

### V3.2.0 登录页交互优化

- 保留浅色双栏登录页及原认证逻辑，输入框统一为浅灰蓝底色，并覆盖浏览器自动填充样式；账号、密码不再显示上方字段标签，按钮文案为“立即登录”。
- “记住账号和密码”仅在登录成功后写入当前浏览器的localStorage，下次打开登录页自动带入；取消勾选会立即清除已保存信息。
- 记住的密码以可读取的本地凭据记录保存，不能防止同一浏览器用户或同源脚本读取，公共电脑及共享设备不应使用；服务器会话仍只使用Secure、HttpOnly、SameSite Cookie。

### V3.2 分录级证据链与分摊

- R09回单分录分摊与R01—R07整凭证规则统一编排，同一凭证可同时保留发票、回单及共享合同，不再因命中回单规则而跳过其他财务证据。
- 按“分录＋单据＋收付方向＋分摊金额＋关系类型”保存证据关系，金额以整数分计算。支持一对一、一条分录多回单、一张回单拆到多条分录、部分金额及后续余额使用；复杂多对多、同额多解和全局争用转人工，不按列表顺序抢占。
- 借方银行分录核验收款账号，贷方核验付款账号；日期窗口、红字同号、作废单据、剩余额度和已完成凭证占用均在自动及人工提交时校验。合同、审批单作为共享引用，不消耗金额，也不与发票、回单混合凑算。
- “智能匹配 → 手工匹配／凭证号证据链 → 人工复核／分摊”可逐条分录选择多份回单、填写每份分摊金额和复核依据；分摊合计不等于分录金额时禁止保存。自动匹配、证据完整和正式归档分别校验，附件缺失不能使用“无需外部附件”豁免。
- 本版未引入账套管理。财务工作区仍采用当前浏览器本地存储，未迁移为跨设备服务端共享。

## 独立云服务器部署

独立 Linux 部署使用 Node.js 24、SQLite 和 Nginx，保留当前网站的登录权限及全部浏览器财务功能。运行 `npm run build`、`npm run test:server`、`npm run package:server` 生成白名单安装包；安装、HTTPS、开机自启、备份和更新方法见 [汇通云服务器部署说明](deploy/README.md)。账号数据库保存在服务器的持久目录，财务原件及业务记录仍保存在访问者的浏览器中。更换网址不会自动迁移旧网址下的浏览器数据或已有 Sites 账号。

## Java业务后端

详见 [backend/README.md](backend/README.md)。需要JDK17、Maven3.9、MySQL8、Redis7。复制 `backend/.env.example` 为未跟踪的本地配置并填入自己的值，按说明初始化与启动。

Java后端包含ERP导入、金额与名称清洗、策略及责任链匹配、Redis分布式锁、人工关联、PDFBox原件合并、哈希校验和关系检索。OCR默认关闭，配置PaddleOCR网关后可用；其他云OCR保留接口。

当前在线工作区没有自动把浏览器财务数据迁移到Java后端；Java业务API也尚未接入Worker账号认证和租户隔离。正式部署Java服务前需完成对应接入、授权及实际ERP/OCR联调。
